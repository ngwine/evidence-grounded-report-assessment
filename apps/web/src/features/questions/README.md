# Questions – Giao diện câu hỏi vấn đáp

Feature hiển thị **câu hỏi có mục tiêu** được sinh từ vấn đề, evidence và
tiêu chí rubric.

## Chức năng

- Hiển thị danh sách câu hỏi được sinh ra, mỗi câu liên kết với vấn đề hoặc
  evidence cụ thể.
- Cho phép giảng viên chấp nhận, chỉnh sửa hoặc loại bỏ câu hỏi trước khi
  sử dụng.
- Phân loại câu hỏi theo loại: claim chưa có bằng chứng, kết luận chưa hỗ trợ,
  phương pháp chưa giải thích, nội dung tương đồng cao, không nhất quán.
- Liên kết câu hỏi với vị trí cụ thể trong báo cáo.
