# Feedback – Giao diện Feedback Log

Feature hiển thị **Feedback Log** – lịch sử chỉnh sửa của giảng viên đối với
kết quả hệ thống.

## Chức năng

- Hiển thị lịch sử chỉnh sửa: kết quả gốc, hành động (accept / edit / reject),
  giá trị sau chỉnh sửa, timestamp.
- Bộ lọc theo báo cáo, tiêu chí, loại hành động.
- Thống kê tổng quan: tỷ lệ accept, edit, reject theo tiêu chí.
- Xuất dữ liệu phục vụ phân tích sai số và đánh giá thực nghiệm.
