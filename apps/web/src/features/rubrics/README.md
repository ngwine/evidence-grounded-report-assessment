# Rubrics – Giao diện quản lý Rubric

Feature cho phép giảng viên **định nghĩa và quản lý rubric** đánh giá.

## Chức năng

- Tạo rubric theo template chuẩn: tiêu chí, checklist, trọng số, mức đánh giá
  và quy tắc quyết định.
- Chỉnh sửa, sao chép và quản lý phiên bản rubric.
- Xem preview rubric trước khi áp dụng cho đánh giá.
- Gán rubric cho báo cáo hoặc nhóm báo cáo.
