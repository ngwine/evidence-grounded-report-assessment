# Similarity – Giao diện Similarity Report

Feature hiển thị kết quả **Pipeline 1 – Phát hiện nội dung tương đồng**.

## Chức năng

- Hiển thị Similarity Report: tỷ lệ tương đồng tổng thể, danh sách đoạn
  nghi vấn, loại tương đồng (verbatim / paraphrase / summary) và tài liệu nguồn.
- Highlight đoạn tương đồng trong báo cáo gốc với liên kết đến nguồn đối chứng.
- Cho phép giảng viên kiểm tra từng cặp đoạn và xác nhận hoặc bỏ qua.
- Bộ lọc theo loại tương đồng, mức độ confidence, chương/mục.

## Lưu ý

- Tỷ lệ tương đồng ≠ tỷ lệ đạo văn. Giao diện phải thể hiện rõ đây là thông
  tin hỗ trợ, không phải kết luận.
