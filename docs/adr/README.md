# Architecture Decision Records

Đặt file theo mẫu `ADR-NNN-ten-ngan.md`. Mỗi ADR tối thiểu có:

- trạng thái và ngày;
- bối cảnh/vấn đề;
- các phương án đã xem xét;
- quyết định và lý do;
- hệ quả, rủi ro và điều kiện xem xét lại.

Quyết định cần ADR sớm: MongoDB deployment/search, queue, file storage,
parser, embedding/reranker/LLM và Search Provider.
